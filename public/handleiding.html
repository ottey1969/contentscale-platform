Complete User Guide

Everything you need to know about the AI-Powered SEO Audit System

OVERZICHT

Wat is dit systeem?

ContentScale is een AI-aangedreven SEO audit systeem dat je helpt om pagina's te optimaliseren voor hogere posities in Google. Het systeem combineert:

  • Bulk Scan — Importeer Google Search Console data en zie alle pagina's met automatische prioritering
  • Workflow Manager — Organiseer en prioriteer welke pagina's je eerst optimaliseert
  • Deep Dive (PULSE+NEXUS) — Gedetailleerde analyse van een enkele pagina met AI-aangedreven concurrent analyse
  • AI Competitor Analysis — Upload HTML van concurrenten en laat AI zwakheden vinden
  • Surgical Recommendations — Exacte content voorbeelden die je direct kunt copy-pasten
HET COMPLETE PROCES

6 Stappen van Start tot Finish

1
BULK SCAN — Importeer GSC Data
Upload je Google Search Console CSV bestanden (Pages + Queries). Het systeem berekent automatisch een prioriteitsscore voor elke pagina op basis van positie (11-30 = quick wins), impressies (hoge vraag) en CTR (makkelijk te verbeteren).
/audit-workflow → Import GSC CSV
2
WORKFLOW MANAGER — Organiseer & Prioriteer
Zie alle geïmporteerde pagina's met hun scores. Filter op prioriteit (🔥 CRITICAL, ⚡ HIGH, 📊 MEDIUM). Selecteer een pagina en klik op "🔬 Open in PULSE+NEXUS" om de deep dive analyse te starten. Alle data (URL, keyword, GSC metrics) gaat automatisch mee.
/audit-workflow → Pagina lijst
3
DEEP DIVE — Gedetailleerde SEO Analyse
Het SEO Audit scherm opent met automatisch ingevulde velden. Verifieer handmatig het primary keyword (AI vindt mogelijk niet het beste). Zoek de top 3 concurrenten in Google, open hun pagina's, klik rechts → "Paginabron bekijken" (Ctrl+U) → Alles selecteren (Ctrl+A) → Kopiëren (Ctrl+C) → Plakken in de 3 tekstgebieden.
/seo-audit (via workflow)
4
AI COMPETITOR ANALYSIS — HTML Verificatie
Klik "🤖 Analyze Competitors + Generate Recommendations". AI analyseert de HTML code van concurrenten en vindt: FAQ schema errors, meerdere H1 tags, ontbrekende alt text, tabellen, expert quotes. Je ziet exact wat zij fout doen en hoe jij het beter kunt. Duurt 30-60 seconden.
POST /api/audit/analyze-competitors
5
SURGICAL RECOMMENDATIONS — Exacte Content
AI genereert EXACTE voorbeelden die je direct kunt gebruiken: perfecte title (62 tekens), meta description (158 tekens), H1, FAQ schema (compleet JSON-LD), comparison table (HTML), expert quotes, statistieken. Elke sectie heeft een [📋 Copy] knop. Geen vage suggesties — kant-en-klare content.
POST /api/audit/generate-recommendations
6
TRACKING — Monitor Resultaten
Klik "← Return to Workflow" om terug te gaan. De pagina wordt automatisch gemarkeerd als "Done" ✅. Importeer elke 7-14 dagen nieuwe GSC data om vooruitgang te zien: positie verandering, clicks verandering, CTR verbetering. Maak screenshots van GSC voor klanten als bewijs.
/audit-workflow → Status tracking

De 3 Hoofd Componenten

1. Workflow Manager (Bulk Scan)
/audit-workflow
Doel: Importeer Google Search Console data en zie alle pagina's met automatische prioritering.

Wat het doet:
• Upload Pages CSV (Google → Performance → Pages → Export CSV)
• Upload Queries CSV (Google → Performance → Queries → Export CSV)
• Systeem berekent score per pagina (0-100)
• Score = positie kans (40pt) + zoekvolume (30pt) + CTR potentieel (20pt) + commercial intent (10pt)
• Filter op 🔥 CRITICAL (90+), ⚡ HIGH (60-89), 📊 MEDIUM (40-59)
• Klik "🔬 Open in PULSE+NEXUS" om deep dive te starten

Data flow: URL, keyword, positie, impressies, clicks, CTR gaan automatisch mee naar SEO Audit.
2. PULSE+NEXUS (Deep Dive)
/seo-audit
Doel: Gedetailleerde analyse van één pagina met AI-aangedreven concurrent analyse.

3 Modi:
• DEEP DIVE MODE — Vanuit Workflow (single page focus)
• BULK SCAN MODE — Direct CSV import (multiple pages)
• MANUAL MODE — Direct bezoek aan /seo-audit

Hoe het werkt:
1. Pagina opent met auto-gevulde velden (als vanuit Workflow)
2. Notificatie: "✅ Workflow Data Loaded! 📊 X pages, Y queries"
3. Verifieer/update handmatig het primary keyword
4. Plak HTML van 3 concurrenten (View Source → Ctrl+A → Ctrl+C → Ctrl+V)
5. Klik "🤖 Analyze Competitors"
6. Wacht 30-60 seconden terwijl AI analyseert
7. Zie resultaten: concurrent zwakheden, HTML errors, kansen
8. Klik "← Return to Workflow" (auto-marks done)

Waarom handmatige HTML input? Automatische parsers zijn niet perfect. Door zelf HTML te kopiëren krijg je exacte analyse van wat Google ziet.
3. AI Recommendations
POST /api/audit/generate-recommendations
Doel: Genereer chirurgisch precisie content voorbeelden die direct bruikbaar zijn.

• H1 — Single, keyword-rijk
• H2 Structuur — 5-7 koppen in logische volgorde
• Introductie (60-80 woorden) — Direct answer format
• FAQ Schema — Complete JSON-LD code
• Comparison Table — HTML <table> code

• Statistieken — 5-7 data points (2023-2024)

Elke sectie heeft een [📋 Copy] knop!

VEELGESTELDE VRAGEN

FAQ

Waarom handmatige HTML input?

Automatische HTML parsers zijn niet 100% betrouwbaar. Door zelf HTML te kopiëren (View Source), krijg je de EXACTE code die Google ziet. AI kan dan schema errors, heading fouten, en andere technische problemen precies identificeren.

Waarom moet ik het primary keyword handmatig verifiëren?

AI kan keywords vinden in GSC data, maar weet niet altijd welk keyword jij wilt targeten. Soms wil je een variant of long-tail keyword. Daarom: altijd handmatig verifiëren/aanpassen.

Wat is het verschil tussen BULK SCAN en DEEP DIVE?

BULK SCAN: Importeer CSV, zie alle pagina's (50-200+), quick priority scores.
DEEP DIVE: Focus op 1 pagina, concurrent analyse, surgical recommendations.

Hoe werkt multi-country targeting?

Systeem ondersteunt meerdere landen. Jij stelt in: primaryCountry: "nl", secondaryCountries: ["be", "lu"], globalCountries: ["us"]. Google gebruikt dit via hreflang tags, domain (.nl), en content language.

Wat kost dit?

Gemini API: GRATIS (60 requests/min)
Server hosting: Afhankelijk van je provider (Railway ~$5/maand)
Totaal: ~$5/maand voor onbeperkt gebruik

Hoe track ik resultaten?

Importeer elke 7-14 dagen nieuwe GSC data. Workflow Manager toont automatisch: oude vs nieuwe positie, clicks verandering, CTR verbetering. Maak screenshots voor klanten als bewijs.

Wat als AI geen JSON teruggeeft?

Soms retourneert AI invalid JSON. System logt de raw response in console. Check server logs, zie wat AI zei, debug. Meestal: prompt te complex → simplify of probeer minder competitors tegelijk.

How do I track results?

What if AI doesn't return JSON?
